# 🚀 Easy Investimentos

O **Easy Investimentos** é uma plataforma full-stack de gestão financeira e análise de ativos, desenvolvida para proporcionar uma experiência intuitiva e segura para investidores. O projeto foca em escalabilidade e performance, utilizando as melhores práticas de desenvolvimento moderno.

## 🛠️ Tecnologias Utilizadas

### **Frontend**

  * **Angular 20**: Framework principal para uma SPA (Single Page Application) robusta.
  * **Angular Material**: Componentização e interface baseada em Material Design 3.
  * **Reactive Forms**: Manipulação de formulários complexos com validações assíncronas.
  * **TypeScript**: Tipagem estática para maior segurança no código.

### **Backend (Em desenvolvimento)**

  * **Java & Spring Boot**: Core da aplicação para regras de negócio e segurança.
  * **Spring Security**: Autenticação e autorização (JWT).
  * **PostgreSQL**: Banco de dados relacional para armazenamento de ativos e usuários.

-----

## 📌 Funcionalidades Principais

  * [x] **Home Page:** Landing page responsiva com seções de calculadora e CTA.
  * [x] **Cadastro de Usuários:** Formulário dinâmico com validações de CPF, endereço e segurança.
  * [ ] **Dashboard Financeiro:** Visualização de saldo, rendimentos e gráficos de alocação.
  * [ ] **Simulador de Investimentos:** Calculadora em tempo real para projeção de juros compostos.
  * [ ] **Autenticação Segura:** Sistema de Login integrado ao backend.

-----

## 📂 Estrutura do Repositório

O projeto utiliza uma estrutura de **Monorepo** para facilitar a organização:

  * `/frontend`: Código fonte da interface em Angular.
  * `/backend`: API REST desenvolvida em Java/Spring Boot.

-----

## 🔧 Como Executar o Projeto

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/seu-usuario/easy-investimentos.git
    ```

2.  **Execute o Frontend:**

    ```bash
    cd frontend
    npm install
    ng serve
    ```

    Acesse: `http://localhost:4200`
